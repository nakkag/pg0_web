AIでプログラミング

AIにお願いして、PG0のプログラムを作ってもらう方法です。むずかしい操作はいりません。AIに「こんなプログラムを作って」とたのむだけです。

どんなことができるの?

PG0には、AIがプログラムを作るための「入り口(API)」があります。AIはこの入り口を使って、次のことができます。

プログラムを作る

あなたのお願いどおりに、PG0のプログラムを書きます。

ちゃんと動くかためす

作ったプログラムを自分で動かして、まちがいがあれば直します。

オンラインに保存する

できあがったプログラムを保存して、開くためのURL(リンク)を教えてくれます。

あなたは、AIが教えてくれたURLを開くだけで、このエディタでプログラムを動かしたり、中身を見たり、自分で書きかえたりできます。

用意するもの

  • インターネットを見られるAI。 たとえば Claude Code や、Webを調べられるチャットAIです。AIがインターネットのページを読めることが必要です。
  • パスワードにする言葉。 あとでプログラムを直してもらうときに使います。わすれないようにメモしておきましょう。
お金や登録はいりませんPG0の入り口(API)は、だれでも無料で使えます。

使い方(3ステップ)

  1. AIにお願いする。 下の「お願いの例」をコピーして、作りたいものに書きかえて、AIに送ります。
  2. AIが作って、ためして、保存する。 AIはPG0の説明書を読んでからプログラムを書き、動かしてたしかめ、オンラインに保存します。おわるとURLを教えてくれます。
  3. URLを開いて動かす。 エディタが開くので、▶ボタンで実行します。気に入らないところがあれば、AIに直してもらいます(直してもらうとき)。

保存したプログラムは、エディタのメニューの「オンラインを開く」から、名前で探して開くこともできます。

AIへのお願いの例

お願いの文には、かならずPG0の説明書のURLを入れてください。AIはこの説明書を読んで、PG0の書き方を知ります。「( )」の中は自分で書きかえます。

ふつうのプログラム

PG0.5でプログラムを作ってください。
まず https://pg0.jp/api/agent/v1/manual?lang=ja を読んで、PG0の書き方と使い方を覚えてください。
作ってほしいもの: 1から100までの数のうち、素数だけを表示する。
できたら動かしてたしかめてから、オンラインに保存してください。
名前は「素数さがし」、作者は「(あなたの名前)」、パスワードは「(自分で決めた言葉)」にしてください。
最後に、開くためのURLを教えてください。

ゲーム

PG0.5で、画面をタッチしてあそぶブロックくずしを作ってください。
まず https://pg0.jp/api/agent/v1/manual?lang=ja を読んで、PG0の書き方と画面の使い方を覚えてください。
できたらオンラインに保存してください。実行速度は「待ち無し」にしてください。
名前は「ブロックくずし」、作者は「(あなたの名前)」、パスワードは「(自分で決めた言葉)」です。
最後に、開いてすぐあそべるURLを教えてください。

クイズや計算

PG0.5で、九九のクイズを出すプログラムを作ってください。
まず https://pg0.jp/api/agent/v1/manual?lang=ja を読んでください。
ランダムに問題を出して、答えを入力すると正解かどうか表示してください。10問で終わりにしてください。
できたらオンラインに保存して、名前は「九九クイズ」、作者は「(あなたの名前)」、パスワードは「(自分で決めた言葉)」にして、URLを教えてください。

直してもらうとき

保存したプログラムを直してもらうには、AIにプログラムのIDとパスワードを伝えます。IDは、URLの cid= のうしろにある長い文字列です。

IDが (URLのcid=のうしろの文字列) のプログラムを直してください。パスワードは「(自分で決めた言葉)」です。
ボールがだんだん速くなるようにしてください。
直したら、なにを変えたかをメモに書いて保存してください。

直した内容は「変更履歴」に残ります。前のほうがよかったときは、エディタのメニューの「変更履歴」から前のプログラムを開けます。

名前とパスワードのきまり

  • 名前は、ほかの人と同じにできません。 同じ名前のプログラムがすでにあると保存できないので、AIに別の名前にしてもらいます。
  • パスワードは、直すときと消すときに必要です。 大文字と小文字はどちらでもかまいません。わすれると直せなくなるので、メモしておきましょう。
  • 保存したプログラムは、みんなが見られます。 本名や住所、電話番号などは入れないでください。
  • だれにも見せたくないときは、AIに「非公開で保存して」とお願いします。非公開でも、URLを知っている人は開けます。

ゲームを作るとき

  • AIはゲームの中身(点数の計算やキャラクターの動き)はためせますが、画面の見た目は見られません。 色や文字の位置がおかしいときは、あなたがAIに「文字がはみ出している」「ボールが小さすぎる」のように伝えてください。
  • ゲームは実行速度を「待ち無し」で保存してもらいます。ほかの速度だと、動きがとてもおそくなります。
  • 音が出るゲームは、画面を一度タッチ(またはキーをおす)してから音が鳴りはじめます。

こまったとき

こんなときどうする?
AIが「PG0が分からない」と言うお願いの文に説明書のURL(https://pg0.jp/api/agent/v1/manual?lang=ja)が入っているかたしかめて、「まずこのページを読んで」と伝えます。
「同じ名前があって保存できない」と言われた別の名前にしてもらいます。
「パスワードがちがう」と言われた保存したときのパスワードを伝えます。
プログラムが止まらない、おわらないAIに「無限ループになっていないか調べて直して」と伝えます。
動くけれど、思っていたのとちがうどこがちがうかを、なるべく具体的にAIに伝えます。「10回で終わってほしい」「文字を大きく」など。

もっとくわしく知りたい人へ
