APIでできること

PG0(Web版)には、AIエージェント向けのHTTP APIがあります。エージェントはこのAPIを通じて次のことができます。

書く・確かめる

PG0 / PG0.5のプログラムを書き、構文チェックと実行で動作を確かめます。

保存する

オンラインに保存し、このエディタで開けるURLを返します。修正の履歴も残ります。

ゲームも試せる

画面描画ライブラリを使うゲームも、キーやタッチの操作を与えて動きを検証できます。

エージェント自身が読む詳細な仕様(APIの使い方、言語仕様、ライブラリ)は次のURLにあります。エージェントには、最初にこのマニュアルを読むように伝えてください。

エージェント用マニュアル
https://pg0.jp/api/agent/v1/manual?lang=ja(日本語) / https://pg0.jp/api/agent/v1/manual?lang=en(英語)
機械可読の定義
https://pg0.jp/api/agent/v1/openapi.json(OpenAPI) / https://pg0.jp/api/agent/v1/libraries(関数一覧) / https://pg0.jp/api/agent/v1(索引と制限値)
エージェント向けの入口
https://pg0.jp/llms.txt

必要なもの

  • Webにアクセスできる(HTTPリクエストを送れる)AIエージェント。 例: Claude Code、Web検索やコード実行ができるチャットAI、独自に作ったエージェント。
  • APIキーは不要です。 誰でも使えます。
  • 保存用のパスワード。 後で更新・削除するために使います。エージェントに決めさせるか、指示で与えます。

基本の流れ

  1. エージェントがマニュアル(上記URL)を読み、言語仕様とライブラリを把握する
  2. プログラムを書き、/check で構文チェックする(典型的な間違いは警告として返る)
  3. /run で実行し、出力・戻り値・変数の値を見て動作を確かめる
  4. 期待どおりになるまで 2〜3 を繰り返す
  5. /scripts にオンライン保存する(名前、作者、パスワード、メモ)
  6. 人はエージェントが伝えるURLを開き、エディタで動かして確認する
  7. 修正を頼むと、エージェントは同じスクリプトを更新し、変更内容をメモ(変更履歴)に残す

保存したプログラムは、エディタの「オンラインを開く」から名前や作者で検索して開くこともできます。

エージェントへの指示の例

最初にマニュアルのURLを読むように伝えるのが確実です。そのままコピーして使えます。

ゲーム

PG0.5の画面描画ライブラリ(lib/screen.pg0)を使って、タッチで操作するブロック崩しを作ってください。
https://pg0.jp/api/agent/v1/manual?lang=ja を読み、ヘッドレス実行でゲームのロジックを確かめてください。
画面のプログラムなので実行速度は「待ち無し」(speed: 0)で保存し、開いてすぐ実行できるURL(run_url)を教えてください。

オンライン保存のルール

  • 名前は公開スクリプトの中で重複できません。同じ名前があると保存に失敗します(非公開なら重複できます)。
  • パスワードは更新と削除に必要です。エディタで保存したときと同じ扱いなので、エージェントが保存したものを人がエディタで更新することも、その逆もできます。大文字小文字は区別せず、前後の空白は無視されます。
  • メモはバージョンごとに残り、エディタの「変更履歴」に表示されます。作成時は内容を、更新時は変更点を書くようエージェントに指示してください。
  • 公開スクリプトは誰でも見られます。個人情報などは入れないでください。
エージェントが返す2種類のURLurl はエディタで開くURL、run_url は開いてすぐ実行するURLです。ゲームを人に渡すときは run_url が便利です。
パスワードについて強い保護ではありません。大事な情報を守る用途には使わないでください。

画面(ゲーム)のプログラム

  • 画面描画ライブラリ(lib/screen.pg0)を使うプログラムは、APIでは画面を出さずに実行されます(ヘッドレス実行)。描画の呼び出しが記録され、キーやタッチの操作を時刻付きで与えてゲームの動きを確かめられます。
  • 見た目(レイアウトや色)はAPIでは確認できません。人がエディタで開いて確認してください。
  • 実行速度は「待ち無し」(speed: 0)で保存させてください。他の速度では1文ごとに待ちが入り、画面のプログラムは極端に遅くなります。
  • サウンドは、ブラウザの制限により最初のタップやキー入力の後でないと鳴らないことがあります。

APIの概要

すべて https://pg0.jp/api/agent/v1 の下にあり、リクエストとレスポンスはJSONです。詳細はエージェント用マニュアルにあります。

メソッドパス内容
GET/manual?lang=ja|enマニュアル(Markdown)
GET/openapi.jsonOpenAPI定義
GET/libraries関数一覧
POST/check構文チェック(警告付き)
POST/run実行(出力、戻り値、変数、画面の記録を返す)
GET/scripts保存済みスクリプトの一覧・検索
POST/scripts新規保存
GET/scripts/{cid}取得(コード込み)
PUT/scripts/{cid}更新(パスワード必要)
DELETE/scripts/{cid}削除(パスワード必要)
POST/scripts/{cid}/run保存済みスクリプトの実行
GET/scripts/{cid}/history変更履歴

動作確認の例(curl)

curl -H "Content-Type: application/json" \
     -d '{"code":"#import(\"lib/io.pg0\")\nfor (i = 1; i <= 3; i++) { println(i * i) }"}' \
     https://pg0.jp/api/agent/v1/run

{"status":"ok","output":"1\n4\n9\n", ...}

制限

  • 1回の実行は標準5秒(最大30秒)。実行文数やメモリにも上限があります。長い処理は分割するか、ゲームならフレーム数の上限(max_frames)で区切ります。
  • 同時に実行できる数には上限があり、超えると少し待ってから再試行するよう応答します(429)。
  • 実際の値は https://pg0.jp/api/agent/v1 の limits に載っています。
  • ライブラリの読み込み(#import)は lib/math.pg0、lib/string.pg0、lib/io.pg0、lib/screen.pg0 のみです。URLや他のファイルは読み込めません。

うまくいかないとき

症状対処
保存で「名前が重複」(409)別の名前にするか、非公開(private: 1)で保存させる。
更新や削除で「パスワード不一致」(401)保存時のパスワードを伝える。
実行結果が status: "timeout"無限ループか処理が重すぎる。画面のプログラムなら max_frames を指定させる。
「スクリプトまたはライブラリの読み込みに失敗しました」対応していない #import を使っている。
言語仕様の勘違い(if の波括弧、ブロック内の変数、文字列の演算など)マニュアルの「注意点チェックリスト」を読むよう伝える。
